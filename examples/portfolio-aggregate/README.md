# 作品集脱敏汇总证据

本目录只公开**私有受控原型（private controlled prototype）的已核验汇总值**。它不包含私有任务、原始轨迹、内部网页、用户数据或公司代码。

必须正确理解证据边界：

- 可以公开复核：成功数/总数对应的百分比、McNemar 口径、三轮 Token 汇总、Memory 步数与 Token 算术，以及不同实验不能混为一组；
- 无法从本仓库复现：模型调用、浏览器执行、原始任务、原始轨迹和私有评测结果；
- 因此本目录是 **aggregate-only evidence**，不是“公开可复现实验”。

运行本地算术与统计口径校验。校验器还会拒绝未知字段，并扫描常见密钥、凭据和绝对路径模式；该模式扫描是发布前防线，不等于对所有语义隐私做形式化证明：

```bash
npm run portfolio:validate
```

输出：`reports/portfolio-aggregate-validation.json`。

## 口径说明

- 系统 A/B 的 `81/108 → 106/108` 是三轮合并口径；
- 系统 Token 降幅 `30.48%` 是三轮各自总 Token 降幅的算术平均，目录中保留三组条件级总量用于复算；
- `F2P=8 / P2F=0` 是首轮配对迁移口径，不能拿来反推三轮每一轮的变化；
- Memory `89/90 → 88/90` 是独立的 Memory off/on 实验；
- Memory 效率变化由总步骤 `508 → 483`、总 Token `4,484,954 → 4,337,868` 复算，且同时披露 2 次负迁移；
- Hard 首轮是 `Single 12/12` 与 `Multi 10/12`，两个失败项修复后先完成定向回归 2/2；后续使用 `sensenova-6.8-flash-lite` 重新完整执行 12 条配对任务（24 个条件），Single 与 Multi 均为 `12/12`，完整性校验通过且 Provider 基础设施失败为 0；
- 完整复跑中 Single 总步骤/Token 为 `37 / 336,659`，Multi 为 `69 / 858,477`。这说明本任务集上 Multi 没有成功率收益且开销更高，支持“按难度动态路由”，不支持“Multi 必然更强”；
- 复合任务 `2/6 → 6/6` 是另一套任务集，不与 36 条系统基准合并计算。
